# Handwritten Digit Recognition — KNN & SVM on MNIST

A complete Data Science project comparing **K-Nearest Neighbours (KNN)** and
**Support Vector Machine (SVM)** for recognising handwritten digits (0–9) using
the MNIST dataset.

---

## 📊 Results Summary

> Numbers below are produced by actually running the models on the 10,000-sample MNIST test set (`outputs/results.csv`).

| Metric | KNN (k=3) | SVM (RBF, C=10) |
|---|---|---|
| **Accuracy** | 0.9705 (97.05%) | **0.9767 (97.67%)** |
| **Precision (Macro)** | 0.9709 | **0.9768** |
| **Recall (Macro)** | 0.9701 | **0.9765** |
| **F1 Score (Macro)** | 0.9704 | **0.9766** |
| **Train Time (s)** | ~0.1 s (lazy fit) | 73.8 s (20k subset) |
| **Pred Time (s on 10k)** | 16.22 s | 79.97 s |

*Secondary Experiment:* **SVM with PCA (50 components)** trained on all 60,000 samples achieved **98.68% accuracy** in **64.1 s** training time.

### Robustness Summary (`outputs/robustness_results.csv`)

| Condition | KNN Accuracy | SVM Accuracy | KNN Drop | SVM Drop |
|---|---|---|---|---|
| **Clean (Baseline)** | 0.9705 | **0.9767** | 0.0000 | 0.0000 |
| **Gaussian Noise (σ=0.1)** | 0.9714 | **0.9735** | -0.0009 | +0.0032 |
| **Rotation (±15°)** | 0.9580 | **0.9634** | +0.0125 | +0.0133 |
| **Shift (±3 px)** | 0.5647 | **0.6060** | +0.4058 | **+0.3707** |

## 📝 Notebook Sections

1. Introduction and Problem Statement
2. Load MNIST (60k train / 10k test, 28×28, 10 classes)
3. Exploratory Data Analysis — sample grid, class distribution, average images, pixel histogram
4. Preprocessing — normalisation (0→1), flattening (784 features), rationale
5. KNN Model — `KNeighborsClassifier(n_neighbors=3)`
6. SVM Model — `SVC(C=10, kernel='rbf', gamma='scale')` + PCA experiment
7. Evaluation — accuracy/precision/recall/F1, timing, comparison table & bar chart
8. Confusion Matrices — seaborn heatmaps
9. Error Analysis — confused pairs (3↔5, 4↔9, 7↔1), misclassified image grids
10. Robustness Test — Gaussian noise, rotation, shift
11. Conclusion and Future Work
